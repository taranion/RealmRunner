# RealmRunner_WASM Submodule

This submodule compiles the core Java MUD client engine (`MUDClient-Base`) into a WebAssembly (WASM) module using **Oracle GraalVM Native Image Web Image backend** (`native-image --tool:svm-wasm`).

---

## Architectural Principles

1. **Pure Java Execution in WebAssembly**:
   - Compiles `MUDClient-Base`, `TelnetProtocol`, `GMCP4J`, `libansi`, `libmxp`, and `MUDEventBus` directly to WasmGC.
   - Eliminates duplicate protocol parser implementations in JavaScript/TypeScript.

2. **Push Transport & JS Interop (`@JS` Web Image API)**:
   - Uses Oracle GraalVM official `@JS` annotation from `org.graalvm.webimage.api.JS`.
   - `WasmSessionBridge`: Manages Java session initialization and sets up `globalThis.WasmSessionBridge` JS object.
   - Single Abstract Method (SAM) proxies bridge `Consumer<JSValue>` with `.asString()` for string dispatch.
   - `WasmBrowserTransport`: Implements `MUDTransport` to bridge raw binary frames between browser WebSockets and Java decoders via hex dispatch.

3. **Module & ServiceLoader Configuration (`module-info.java`)**:
   - Declares `provides java.lang.System.LoggerFinder with org.prelle.realmrunner.wasm.WasmLoggerFinder;` to handle `System.Logger` under WASM.
   - Maven compiler requires `<parameters>true</parameters>` and `--add-reads org.prelle.realmrunner.wasm=ALL-UNNAMED`.

## Build Commands

- **Environment Requirement**: Requires Oracle GraalVM 25 JDK (`JAVA_HOME=/opt/graalvm-25.2.4+7.1`).
- **Standard Compile (Java Bytecode)**:
  ```bash
  JAVA_HOME=/opt/graalvm-25.2.4+7.1 mvn clean compile -pl RealmRunner_WASM -DskipTests -Dmaven.javadoc.skip=true
  ```
- **WebAssembly Native Image Build**:
  ```bash
  JAVA_HOME=/opt/graalvm-25.2.4+7.1 mvn package -pl RealmRunner_WASM -Pnative -DskipTests -Dmaven.javadoc.skip=true
  ```

## Local CLI Testing (Node.js)

To test WebAssembly execution locally without opening a web browser:
```bash
node target/realmrunner-web.js
```

To run end-to-end integration test against live MUD server on `ws://localhost:4002/`:
```bash
node -e "
const fs = require('fs');
globalThis.fetch = async (url) => ({ arrayBuffer: async () => fs.readFileSync(url) });
require('./target/realmrunner-web.js');
setTimeout(() => {
    const bridge = globalThis.WasmSessionBridge;
    bridge.setLineListener(line => console.log('>>> [LINE]:', line));
    const ws = new WebSocket('ws://localhost:4002/', ['telnet.mudstandards.org']);
    ws.binaryType = 'arraybuffer';
    bridge.setSendListener(bytes => { if (ws.readyState === WebSocket.OPEN) ws.send(bytes.buffer); });
    ws.onmessage = e => bridge.feedBinaryData(new Uint8Array(e.data));
}, 500);
"
```

## Build Output Artifacts & Auto-Copy

- **`target/realmrunner-web.js`**: JavaScript embedding loader (~112 KiB) generated by GraalVM Native Image.
- **`target/realmrunner-web.js.wasm`**: Compiled WebAssembly GC binary (~13.5 MiB).
- **Auto-Copy Target**: Maven `maven-resources-plugin` automatically copies these files to `../RealmRunner_Web/` during `mvn package -Pnative`.

## GraalVM Native Image Flags (`pom.xml`)

- `<buildArg>--tool:svm-wasm</buildArg>`: Activates GraalVM WasmGC compilation target.
- `<buildArg>-H:+UnlockExperimentalVMOptions</buildArg>`: Enables experimental VM features.
- `<buildArg>--initialize-at-build-time=org.prelle,com.google.gson</buildArg>`: Initializes `org.prelle.*` and `Gson` at build-time.
- `reflect-config.json`: Contains full reflection metadata for ANSI commands, Telnet options, and GMCP.

## JS Interop Contract (`WasmSessionBridge`)

- **Java $\rightarrow$ JS Exported Methods**:
  - `initSession()`: Instantiates `MUDSession`, `WasmBrowserTransport`, `TelnetOptionManager`, and `SessionPipelineFactory`.
  - `feedBinaryData(byte[] | ArrayBuffer | Uint8Array)`: Converts bytes to hex and pushes into `TelnetStateDecoder`.
  - `sendText(String)`: Sends user terminal input strings to `MUDSession`.
- **JS Callbacks Registered**:
  - `setLineListener`: Emits clean VT500 stream lines to `Ghostty-Web` / `xterm.js`.
  - `setGMCPListener`: Emits GMCP command POJOs to room/vitals/map UI components.
  - `setSoundListener`: Emits sound events to HTML5 Audio.
  - `setSendListener`: Emits outgoing Telnet bytes back to `WebSocket.send()`.
